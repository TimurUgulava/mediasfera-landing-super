# Медиасфера — посадочная (вариант B + два главных экрана)

Посадочная агентства **Медиасфера** под трафик из рейтинга контент-агентств. За основу взят **вариант B «живая бумага»**; внесены правки по обратной связи команды и сделаны **два варианта главного экрана**. Остальной контент одинаковый — отличается только первый экран.

## Что поменялось по комментариям команды

- **Курсор-перо** вместо «кошки-мышки» — клик срабатывает мгновенно, чернильный след не перехватывает события.
- **Тёмный блок-мостик** (перенос из «кинематографа») перед каналами/ПромоСтраницами: «мало написать — текст нужно довести до продаж: написать и продвинуть».
- **FAQ и форма разведены** — по кнопке «Обсудить задачу» попадаешь точно на форму, а не на заголовок вопросов.
- **Лид-магнит «Продаст или нет» заметнее** — кнопка в шапке + зафиксированная закладка сбоку (на мобайле — пилюля снизу).
- Убраны стикеры-животные, рукописные красные пометки крупнее и читаемее.
- **Два варианта первого экрана** — выбираем главный экран.

## База (сохранено из B)

Белый лист на лёгком фоне, красный — только акцент, «живая бумага» (лист наклоняется/плавает за курсором), рукописные пометки (на узких переезжают в поток под фразу, не прячутся), спокойная сетка цифр, кейсы с цифрами до денег, без цен, рейтинг не на первом экране.

Проверено на **1440 / 1280 / 1024 / 768 / 390** — без горизонтального скролла и наездов. Чистый HTML/CSS/JS, только Google Fonts. Лид-магнит — демо-заглушка; для живого AI нужен бэкенд.
