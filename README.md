# Медиасфера — посадочная (3 анимированных варианта)

Посадочная страница агентства **Медиасфера** под трафик из рейтинга контент-агентств. Концепция: **белый лист-документ** на лёгком воздушном off-white фоне, рукописные правки на полях, красный `#E30613` — только акцент. Одна идея в трёх характерах движения.

👉 **Живое превью (GitHub Pages):** см. ссылку в описании репозитория (вкладка Pages).

| Вариант | Характер | Файл |
|---|---|---|
| **A — чистая редакция** | строгий редакторский характер; «сюжет» правки текста в hero, 3D-наклон кейсов, живой лид-магнит | [a.html](a.html) |
| **B — живая бумага** | самый интерактивный и самый чистый; лист физически наклоняется/плавает за курсором, спокойная сетка цифр | [b.html](b.html) |
| **C — кинематограф** | самый «дорогой»; scroll-scrub сюжет, parallax-глубина, тёмная драматичная сцена, магнитные элементы | [c.html](c.html) |

Точка входа — **[index.html](index.html)** (разводящая с превью).

## Что заложено

- Белый лист по центру, фон лёгкий (off-white), **красный — только акцент** (логотип, маркер, CTA).
- Рукописные красные пометки на полях; на узких экранах они **не прячутся**, а переезжают в поток под свою фразу.
- Жёлтый маркер, диффы «было → стало», hero-«сюжет» редактуры текста.
- ~5 компактных секций: hero → как доводим до продаж → кейсы → редакция + Яндекс → финал (FAQ + форма).
- Один CTA «Обсудить задачу», лид-магнит «Продаст или нет», без цен, рейтинг не на первом экране.
- Много плавного интерактива (у каждого варианта — свой); на тач/`prefers-reduced-motion` тяжёлое движение отключается, контент полностью виден без JS.

## По итогам обсуждения с командой (последняя итерация)

- **Убраны стикеры-животные** (коты/собаки) во всех трёх.
- **Рукописные красные пометки крупнее** (+12–16%) и читаемее.
- **Чище от «шума»**: меньше акцентов и игры шрифтами, больше воздуха.
- **Интерактива больше** — «крутится, вертится и работает огненно», но плавно и без визуального мусора.

Проверено на ширинах **1440 / 1280 / 1024 / 768 / 390**: без горизонтального скролла и наездов, все пометки видимы и привязаны к фразам.

Чистый HTML/CSS/JS, без сборки, только Google Fonts. Лид-магнит на хостинге — демо-режим (заглушка); для живого AI нужен бэкенд-эндпоинт.
